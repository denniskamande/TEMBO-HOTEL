# Tembo Hotel Data Analysis & Power BI Dashboard

##  Project Overview

The Tembo Hotel Data Analysis project focuses on transforming raw hotel booking data into meaningful business insights using **PostgreSQL and Microsoft Power BI**.

The project covers the complete analytical workflow, including data cleaning, data validation, SQL analysis, KPI development, and interactive dashboard creation.

The analysis explores hotel revenue, bookings, room performance, cancellations, customer locations, payment methods, staff performance, and monthly revenue trends.

---

##  Project Objectives

The main objectives of this project were to:

- Clean and validate raw hotel booking data
- Identify and handle data quality issues
- Analyze hotel revenue and booking performance
- Calculate cancellation rates by room type
- Analyze revenue lost through cancellations and no-shows
- Identify the busiest and quietest months
- Analyze month-over-month revenue growth
- Evaluate staff and department performance
- Analyze revenue by payment method and customer city
- Build an interactive Power BI dashboard for decision-making

---

##  Tools & Technologies

- **PostgreSQL** – Data cleaning, transformation, and analysis
- **SQL** – Aggregations, filtering, CTEs, window functions, and calculations
- **Power BI** – Interactive dashboard development and visualization
- **DAX** – Measures and calculated metrics
- **Excel** – Initial data handling and preparation
